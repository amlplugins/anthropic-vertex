# @amlplugins/anthropic-vertex

Native `@anthropic-ai/vertex-sdk` SDK re-exported under the `@amlplugins` namespace.

> Anthropic on Google Vertex AI — Claude models invoked through Google Cloud Vertex AI region endpoints.

## Install

```bash
npm install @amlplugins/anthropic-vertex
```

## Use

```ts
import { /* named exports from @anthropic-ai/vertex-sdk */ } from "@amlplugins/anthropic-vertex";
// or
import sdk from "@amlplugins/anthropic-vertex";
```

Built and published by GitHub Actions on every push to `main`.

Part of the amlplugins family — see https://github.com/amlplugins.
